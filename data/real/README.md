# Real site data (not in this repository)

Four anonymised Powerverse generation series were used in the original group project. They are company-supplied and are **not** published here.

If you have permission to use the original files locally, place them at:

```
data/real/validation_Data.csv
data/real/solar_data.csv
data/real/site_params.csv
```

Notebooks `02_yearly_envelope.ipynb` and `03_denoising.ipynb` fall back to `data/synthetic/sample_site_0.csv` when these files are absent.
